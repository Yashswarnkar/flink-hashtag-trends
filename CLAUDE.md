# CLAUDE.md

Before doing anything in this repo, read `docs/PLAN.md`. It holds the decisions, pinned
versions, data model, phase scope and acceptance checks, and the working agreement.

- Work one phase at a time and stop after each phase for the owner to explore.
- Keep `docs/PLAN.md` current: append to the *Progress log*, record any change in *Deviations*.
- Use `make` targets; they point Docker at the Lima VM (`flink-lab`), never Docker Desktop.
- Commit only when asked; push to `origin` (github.com/Yashswarnkar/flink-hashtag-trends, public) only when asked.
